# Expose Icons

**Restore app icons and names to macOS Mission Control.**

When you disable "Group windows by application", Mission Control strips every app icon and name — leaving a wall of anonymous thumbnails. Expose Icons puts them back: per-window icons, app names and window titles, in real time, on every display and virtual desktop.

## Highlights

- **Per-window app icons** — each Mission Control thumbnail gets the icon of the app that owns it
- **Close & minimize on hover** — window controls right on the icon
- **Quick Return halo** — jump straight back to the window you came from
- **Pinned apps** — permanent colour-coded halos for the apps you care about
- **Every display & desktop** — one overlay per screen, icons follow desktop switches
- **Fast & native** — SwiftUI + AppKit, ProMotion-tuned, no private APIs, nothing leaves your Mac
